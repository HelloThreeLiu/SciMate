# SciMate · 科研 Agent 应用

> 面向硕士、博士等科研人员的 AI 科研工作台——用「说人话」的方式，帮他们更快地找文献、写论文、核验引用；同时它又是一个「技能宿主」，能直接加载科研圈子已有的各种 AI 技能。
>
> **AI 是副驾，人才是机长。** 所有产出可核查、由人确认；不代写、不编造。
