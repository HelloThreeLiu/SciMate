# citation-verify · 引用真实性核验（含撤稿检查）

一个面向科研人员的 AI 客户端技能（Skill）：逐条核验稿件参考文献**是否真实存在、作者/年份/卷期是否对得上、是否已被撤稿**，输出一份可读的核验报告。

> 背景：行业实测主流大模型生成的引用中 78%–90% 是编造的；仅 2025 年全球就产生约 14.7 万条虚构引用。引用一篇**已被撤稿**的论文，比不引用更糟。

## 它查什么（对每条引用）

| 核验项 | 手段 |
|---|---|
| 是否真实存在 | DOI 直查 OpenAlex → Crossref；无 DOI 时按题名+作者+年份交叉匹配 |
| 能否打开 | 返回数据库中的 DOI 与链接 |
| 作者/年份/卷期对不对 | 引用原文 vs 数据库记录逐项比对，差异逐条列出 |
| 是否已被撤稿 | OpenAlex `is_retracted` + Crossref 撤稿记录（含 Retraction Watch 数据） |
| 查不到怎么办 | 明确标注「未能核实，请人工确认」——**绝不模糊放行，也绝不编造结论** |

## 安装

适用于任何支持社区技能目录约定的 AI 客户端（Claude Code / Cursor 等）：

```bash
# 方式一：放入全局技能目录
git clone <本仓库> ~/.claude/skills/citation-verify     # 或 ~/.agents/skills/citation-verify

# 方式二：项目级（仅当前项目可用）
git clone <本仓库> <你的项目>/.claude/skills/citation-verify
```

**唯一要求：本机装有 Python 3.9+**（脚本零第三方依赖）。

## 使用

在你的 AI 客户端里直接说：

- 「帮我核验这篇稿子的参考文献」+ 附上文件（PDF/DOCX/TEX/MD 均可）
- 「检查一下这些引用有没有被撤稿的」
- 投稿前体检：「跑一次引用核验」

客户端会抽取参考文献清单并运行脚本；也可手动运行：

```bash
python scripts/verify_citations.py refs.txt -o 引用核验报告.md
```

`refs.txt` 每行一条参考文献。可选环境变量 `CITATION_VERIFY_MAILTO=你的邮箱`（进入 OpenAlex 礼貌池，批量查询更稳）。

## 输出报告长什么样

- **总览表**：各状态条数与占比，含两个口径——
  - 口径一：可核实引用中确认真实存在的比例；
  - 口径二：被标注「未能核实」的比例（对外公开的质量信号）；
- **逐条结果**：按严重程度排序（🚨已撤稿 → ❌疑似编造 → ⚠️DOI未收录/元数据差异 → ❓未能核实 → ✅已核实），每条给出匹配文献、核实途径、差异明细。

## 隐私

脚本只把**每条引用本身的文本**（DOI/题名/作者/年份）发往 OpenAlex 与 Crossref 两个学术元数据公开接口；**稿件全文不出本机**。查询结果在本目录缓存 30 天（`.verify_cache.json`），删除即清除。

## 数据源与诚实性声明

- 主路 [OpenAlex](https://openalex.org)、辅路 [Crossref](https://www.crossref.org)（已并入 Retraction Watch 撤稿数据库），均为免费公开接口；
- 「已核实」= 权威数据库命中，**不等于绝对真实**；「未能核实」≠ 引用有假（图书、中文文献常不在收录范围）；
- 判定阈值故意从严：标题匹配要求作者/年份锚点，宁可多标「未能核实」，不做模糊放行。
