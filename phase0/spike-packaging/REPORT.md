## 三、关键构成（体积账本）

| 组件 | 未压缩 | 打进安装包后（LZMA） |
|---|---|---|
| Tauri 外壳 scimate-spike.exe | 4.4 MB | 计入 33.8 MB |
| Python 内核 scimate-kernel.exe（PyInstaller onefile，纯标准库） | 9.0 MB | 计入 33.8 MB |
| pandoc.exe（静态大二进制） | **233.6 MB** | ≈ 25 MB（压缩率 ~11%） |
| **安装包合计** | — | **33.8 MB** |

> 印证了 PRD 的判断：**阶段一真正的体积风险不在"含 C 扩展的科学计算库"（阶段一无沙箱不打包它们），而在 pandoc**——好在 LZMA 压得动。若未来体积成为问题，备选方案（PRD 已列）：pandoc 改为按需下载，或换 Nuitka。

## 四、过程中发现的问题与处置（给阶段一的输入）

| # | 发现 | 处置 / 对阶段一的要求 |
|---|---|---|
| 1 | **Tauri resources 映射会把资源文件放到安装根目录且丢失 .exe 扩展名**（pandoc → 安装根目录 `pandoc` 无扩展名） | 内核搜索逻辑已兼容（同时找 `pandoc.exe` 与 `pandoc`）；阶段一封装成"资源定位器"统一处理 |
| 2 | **内核进程可能残留**：验证过程中发现 4 个残留的 scimate-kernel.exe | Rust 侧退出钩子已做 `kill()`；但外壳被强杀时钩子不执行——阶段一必须加**内核单实例保护 + 端口冲突检测**（PRD 12.6 检查清单 1「内核崩溃能被自动拉起」的另一半） |
| 3 | tauri-plugin-shell v2 的子进程类型是 `process::CommandChild`（文档常见旧写法 `Child` 会编译失败） | 已记录，写进 spike 代码注释 |
| 4 | pandoc 官方 zip 下载在弱网下易断（实测 exit 18，断点续传恢复） | 阶段一若做"按需下载组件"，必须支持断点续传与校验 |
| 5 | 内核 HTTP 服务目前绑定固定端口 17890 | 多实例/端口占用场景阶段一需处理（动态端口 + 握手协议） |
